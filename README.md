# Transport Search

Search buses, trains, flights and private transfers between any two places via Traveling.com.

## Features
- Search all transport types: flights, buses, trains, private transfers
- Filter by transport mode
- Sort by price, duration, or departure time  
- Multi-segment itineraries with layover details
- Rail pass suggestions for European routes
- Click "Book" to open the booking page on Traveling.com

## Note
Uses the Traveling.com public API. Results and availability may vary.
